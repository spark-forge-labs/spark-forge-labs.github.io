# Narendra Darla: personal profile

A static one-page profile (no build step). Sections: Hero, About, By the numbers, Skills, Projects, Contact.

Publish as a GitHub Pages site: copy this folder's files (`index.html`, `style.css`) to the root of a repo named
`<username>.github.io`, or enable Pages on any repo and point it at the folder.

Preview locally: `python3 -m http.server 8000` then open http://localhost:8000.

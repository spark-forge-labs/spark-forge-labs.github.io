About

What I work on and how I like to build.

My focus is enterprise intelligence: tools that bind the systems engineering teams already use (GitHub, Jira, Slack, Datadog, PagerDuty and docs) into one live graph, so an on-call engineer gets a cited answer in seconds.

Lately that has grown into autonomous delivery. Agents that design a change, write the code and tests, open the pull request, and turn crashes into tracked defects that fix themselves, with a human approving every risky step.

I care about work that is verifiable: every change is traced from intent to spec to plan, tests run before hand-off, and demos run on the real product.
